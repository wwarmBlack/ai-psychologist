# 🕊️ Тихая Гавань — сайт для сессий с ИИ-психологом

Веб-приложение: голосовые сессии с ИИ-психологом на базе DeepSeek.
Бэкенд — Python (FastAPI) + SQLite. Фронтенд — HTML/CSS/JS без фреймворков.

## Возможности

- Регистрация и вход, данные хранятся в базе на сервере (SQLite, файл `app.db`)
- Онбординг-анкета при первом входе (ответы можно менять в профиле)
- 4 ИИ-психолога: разный пол, голос и специализация (тревога, самооценка, отношения, утраты)
- Выбор «постоянного» психолога на главной (⭐)
- Голосовая сессия: вы говорите — ИИ отвечает голосом (+ дублируется текстом, можно писать)
- После сессии — автоматическое текстовое резюме (тема, суть встречи, заключение)
- История сессий с резюме
- Планирование сессий на дату/время, уведомление за час (при открытой вкладке)
- Баланс и привязка карты — демо-режим (реальных списаний нет)

## Запуск

1. Установите Python 3.10+ → https://www.python.org/downloads/ (при установке отметьте «Add to PATH»)

2. В папке проекта откройте терминал и установите зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Получите ключ DeepSeek на https://platform.deepseek.com → API Keys.
   Скопируйте файл `.env.example` в `.env` и вставьте ключ:

   ```
   DEEPSEEK_API_KEY=sk-ваш_ключ
   ```

   ⚠️ DeepSeek не полностью бесплатный — он очень дешёвый (примерно $0.3 за миллион токенов,
   одна сессия — доли цента). Нужно пополнить баланс на их сайте на пару долларов.

4. Запустите сервер:

   ```
   uvicorn server:app --port 8000
   ```

5. Откройте в браузере: http://localhost:8000

## Речь: что используется и почему

**Распознавание (ваш голос → текст):** Web Speech API браузера. Бесплатно, без установки,
качество для русского хорошее. Работает в Chrome и Edge (в Firefox нет). Это лучше Whisper
для сайта: Whisper локально требует сервер с GPU/CPU-мощностями или тяжёлую загрузку модели
в браузер. Если позже захотите качество выше — Whisper через API Groq (есть бесплатный лимит).

**Озвучка (текст → голос):** speechSynthesis браузера. Бесплатно, голоса выбираются по полу
психолога. В Windows/Edge голоса русские и звучат хорошо. Если захотите голос приятнее —
Edge-TTS можно добавить на бэкенд позже (он тоже бесплатный, но требует серверной обработки).

## Обучение ИИ

Файл `prompts.py` — всё «обучение» DeepSeek:
- `BASE_SYSTEM_PROMPT` — рамки работы: не врач, без диагнозов, кризисный протокол (112),
  методика ведения сессии, разговорный стиль для озвучки
- `PSYCHOLOGISTS` — личности 4 психологов (характер, подход, специализация)
- `SUMMARY_SYSTEM_PROMPT` — генерация резюме сессии
- В каждый промпт автоматически подставляется профиль клиента и его ответы из анкеты

Редактируйте `prompts.py`, чтобы менять поведение психологов или добавлять новых.

## Структура

```
server.py        — бэкенд: API, база данных, DeepSeek
prompts.py       — обучение ИИ и каталог психологов
static/index.html, style.css, app.js — фронтенд
app.db           — база данных (создаётся автоматически)
.env             — ваш ключ DeepSeek (создайте из .env.example)
```

## Что нужно для «продакшена» (когда сайт будет публичным)

- HTTPS-домен (без него браузер не даст доступ к микрофону с чужих устройств)

- Серверные push-уведомления (сейчас уведомление работает при открытой вкладке)
